📱 앱에서 직접 계정 삭제하기 (권장)

  1. CaMoim 앱 실행 후 로그인
  2. 하단 탭 마이페이지 진입
  3. 화면 하단 설정 또는 회원 탈퇴 메뉴 탭
  4. 안내에 따라 비밀번호 확인 후 탈퇴 신청
  5. 완료 후 즉시 모든 데이터가 영구 삭제됩니다.

📧 이메일로 삭제 요청하기

앱 접근이 불가능한 경우, 아래 이메일로 가입 시 사용한 이메일 주소를 명시하여 요청해주세요.

support@camoimapp.com

요청 확인 후 7일 이내에 처리해드립니다.

CaMoim Account Deletion

A community app for Korean residents in Canada

📱 Delete from the App (Recommended)

  1. Open CaMoim and log in
  2. Go to My Page from the bottom tab
  3. Tap Settings or Delete Account
  4. Confirm with your password and submit deletion
  5. All data is permanently deleted immediately upon confirmation.

📧 Request via Email

If you cannot access the app, send a deletion request to the email below with the email address used at registration.

support@camoimapp.com

Requests are processed within 7 days.

🗑 Data That Will Be Deleted

  • Account information (email, nickname, hashed password)
  • Profile photo
  • School verification info and student ID images
  • Posts, comments, and likes you authored
  • Chat messages (1:1 conversations)
  • Push notification tokens
  • Block and report history

📦 Data That Will Be Retained

The following data is retained for a limited period to comply with legal obligations or maintain service integrity, after which it is automatically deleted.

  • Access logs and IP addresses: retained for 3 months per Korean Communications Privacy Act
  • Report and moderation records: retained for 1 year to prevent abuse
  • Anonymized statistics
